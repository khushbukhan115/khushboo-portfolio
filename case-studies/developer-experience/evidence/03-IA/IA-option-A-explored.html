Architecture 04 / 10

Persistent affordances.

What lives on every screen regardless of primary. These surfaces are the connective tissue and they are not negotiable per page.

Header strip

Logo · 4 primaries · Search · Copilot · Sign in

Top of every page. Active primary highlighted. Cmd-K opens global search with results grouped by primary.

Breadcrumb

Primary  ›  Secondary  ›  Current

Below the header on every inner page. Click any crumb to jump back. Replaces the L1-L5 chip pattern from the wireframes.

Copilot

Drawer (v1) → Spine (v2)

Always one click away. Layer-aware via metadata. Anchored output renders into the surface, not into a chat thread.

Global search

Cmd-K · grouped by primary

Results listed under Start, Build, Reference, Operate. First three results per primary visible. Up/down navigation.

Language picker

Sticky across pages

Selection persists via localStorage. Code blocks, walkthrough samples, and SDK pages all honour the same selection.

Designer-only · Layer badge

L1–L5 in Figma annotations

The cognitive framework survives in design metadata. Developers never see L1-L5 strings in the product surface.

Responsive behaviour

Below 980px the header collapses to logo + hamburger + Copilot FAB. The 4 primaries become a sheet menu. The breadcrumb survives. Copilot drawer becomes an overlay rather than a docked panel.

Architecture 05 / 10

Routing rules.

Every transition documented in Deliverable 2 re-stated in the chosen vocabulary. Every link the IA promises has a defined source, destination, and trigger.

Start→ReferenceVisitor clicks "Send a request" tile on the capability picker. Lands on a Reference endpoint with the demo key auto-loaded. Banner: "You are using shared sandbox. Upgrade in Start › Get a key."
Start→BuildVisitor clicks "Build an integration" tile. Lands on Build › First integration with topic context preserved as URL param.
Start→OperateVisitor clicks "Monitor production" tile. Lands on Operate › Status. Reza's evaluation path.
Build→ReferenceWalkthrough step contains inline pill-link to the endpoint it calls. URL hash preserves walkthrough state for return.
Reference→OperateEvery endpoint page has "Production behavior" link. Filters Operate to that endpoint's rate-limit, deprecation, and observed errors.
Reference→Build"Used in walkthrough" link on every endpoint page. Opens the walkthrough at the relevant step.
Operate→BuildDeprecation item links to migration walkthrough in Build. If no walkthrough exists, Copilot drafts one inline.
Operate→ReferenceClick any log row → "Reproduce in Try-It" opens the endpoint with the exact request payload pre-loaded.
Copilot↕AnyCopilot routes into and out of every primary. v1: deep-link pills in the drawer. v2: spine cross-fades layers with anchored callout preserved.

Validation 07 / 10

Edge cases.

What the IA does when something is missing, broken, or arriving from elsewhere.

Empty search

Cmd-K returns zero results. Fallback: "We couldn't find that. Try Copilot." Copilot prompt pre-fills with the search query.

Stale URL · old IA

Legacy paths (e.g. /walkthroughs/...) redirect to the new IA node (Build › First integration). A small banner: "This page moved. Bookmarks updated."

404 · genuine miss

Layout includes a primary picker (the four cards), a recent-changes feed, and Copilot prompt: "Looking for something specific?"

External deep-link

Links from email, blog posts, or Copilot output retain context. URL hashes survive ("#param-expand" preserves Copilot callout anchor).

Mobile

Header collapses to hamburger. Four primaries become a sheet menu. Copilot becomes a bottom-right FAB. Layer chip strip from D2 wireframes is hidden (it was design-time only).

No language preference yet

First-time visitor sees cURL by default across the portal. After first language pick, all code blocks honour that selection via localStorage. Reset surface in Start › First call.

OAuth cancelled mid-flow

User lands back on Start › Get a key with the sandbox tier featured. The cancellation is not a dead-end. Modal does not close blank.

Sandbox key revoked

Operate shows revocation event. Affected logs marked. Start › Get a key surface highlights "Generate replacement key" CTA.

Copilot · cross-cutting spine

Copilot is not a primary nav item. It is the persistent cross-layer surface present on every page. v1 ships as an anchored drawer with seeded prompts per primary. v2 collapses the drawer into a 72px vertical rail with L1–L5 nodes for one-click cross-layer routing.

Artifact 09 / 10

Internal-to-external translation.

The cognitive framework stays in strategy documents and Figma annotations. The product surface uses these four labels. This mapping is the contract between the two vocabularies.

Internal (framework)External (surface label)Why this translation
L1 Discovery Start (Discovery half) "What is this?" maps to the entry surface where intent is declared. Covered by What you can build, Why Beacon, Architecture.
L2 Onboarding Start (Onboarding half) "How do I start?" lives under the same primary. Get a key and First call are the L2 surfaces. Tiered auth lives here.
L3 Implementation Build "How do I build?" becomes a single verb. Walkthroughs, recipes, migrations, best practices all live under Build.
L4 Reference Reference Industry-standard term across every competitor portal. Developers recognise it instantly. No translation needed.

Artifact 10 / 10

Trade-offs.

What Option A costs and what it earns. Read alongside Option C for an honest comparison.

What Option A earns

  • Four primaries reads as confident and minimal. Closer to the Stripe and Claude lean.
  • Action verbs translate well across mobile, headers, breadcrumbs, and tabs.
  • Start as a single primary lets the tiered auth ladder and capability picker live on one surface, reinforcing each other.
  • Operate as a verb (not a noun like "Status") signals an active surface, not a passive page. Closer to how SREs talk.
  • Reza and Aria each have first-class entry points (Start › Compliance, Start › Get a key › Anonymous). Their unblocks are one click deep.
  • Faster top-nav scan. Hiring managers absorb four items in under a second.

What Option A costs

  • Start is dense. It holds both discovery and onboarding, which means more content competes for above-the-fold space.
  • Reza's evaluation runway is one level deeper. Compliance and Architecture live as secondaries inside Start rather than as their own primary. Marginal cost but real for compliance-first enterprises.
  • "Operate" can read as ops-team-specific to a junior developer who has not yet shipped. Some users will look for "Production" or "Status" instead. Cmd-K mitigates this.
  • The collapse of L1 and L2 hides the distinction the audit named (Discovery is a no-commitment state, Onboarding is post-intent). Lives only in design metadata.
  • Less obvious nav-level evidence of operational maturity for enterprise sales. "Operate" as a primary requires reading deeper to see what is inside.

Recommended when

The portal's primary audience is solo developers, prototyping teams, or startups where speed-of-evaluation is the top concern. Sister option (C) is recommended when enterprise sales motion is dominant and operational maturity must be visible at the nav level.
