What frustrates them

SDK-only docs that assume she'll code. Jargon treated as common knowledge. Error pages with no plain-English summary.
Code samples that skip the import. OAuth explained conceptually but not operationally. AI suggestions referencing three libraries he doesn't know.
"It works in the docs but not in my code." Auth that explains OAuth but not where to click in the provider dashboard.
SDK-only portals hiding the HTTP layer. Missing error response shapes. AI that summarises away the precision she's looking for.
Portals hiding the OpenAPI spec behind nice rendering. SDKs that lose access to raw HTTP. "Just trust us" answers on rate limits.

What the design must do
Top UX implication
A "by-task" access path alongside SDK-by-language. Plain-English error summaries first; technical detail below. Decision-tree guides. Copilot detects non-developer context and adjusts vocabulary.
A "first integration?" onboarding mode. Walkthroughs that explain rationale. Concept ↔ endpoint bidirectional links. Copilot in explain-mode. Novice-aware error hints.
Playground that works out-of-the-box with safe demo credentials, OR OAuth as the smoothest path in the product. Copilot produces complete runnable code with imports.
HTTP-first as co-equal lens, not buried in a switcher. Capability-first navigation. Error catalogue as first-class IA. Copilot must cite specific docs and link to them.
A "For Architects" access path — direct OpenAPI download, changelog with deprecation history, SDK source links, production-readiness panel per endpoint.

Why this extreme matters
By 2027, most organisations will have Aria-equivalents running automations on the same APIs. A portal that fails her fails the next 5–10 years of API consumption.
Liam becomes Diego in 3–5 years. If his first integration was a frustrating slog, his future team picks competitors. The Copilot teaches him patterns he'll keep.
Diego is the dominant developer pattern at volume. Solving for Diego solves the common case. Failing Diego fails the redesign.
Maya is the gate for considered B2B adoption. She decides whether the API is "production-grade" for her team and writes the recommendation upward.
Reza is the conversion gate for enterprise contracts. Trust signals that pass Reza's test pass everyone else's — he is the design's stress-test.
